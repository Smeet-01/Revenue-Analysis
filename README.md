# Revenue-Analysis

A dynamic **Power BI** dashboard for financial analysis, visualizing target vs. actual sales using pivot tables, charts, and interactive slicers to identify variances across product offerings and time periods.

## Files
- `Revenue Analysis.pbix`: Power BI Desktop report.
- `Data Sets/`:
  - `List of Orders.csv`
  - `Order Details.csv`
  - `Sales target.csv`

## Usage
Open `Revenue Analysis.pbix` in **Power BI Desktop** (if prompted for data source paths, update them to point to your local `Data Sets/` folder).
